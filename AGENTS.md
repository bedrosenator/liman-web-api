# 🤖 Agent Rules (Liman Web API)

## 🚨 Обязательные правила для всех AI-ассистентов и агентов

### 1. Git Workflow & Deployment
* **ВСЕГДА СОЗДАЕМ PULL REQUEST ПЕРЕД ДЕПЛОЕМ!**
* Запрещен прямой коммит/пуш в `main` или запуск деплоя без предварительно оформленного Pull Request.
* Любые изменения разрабатываются в отдельной ветке (`feat/...`, `fix/...`), тестируются, пушатся в GitHub и оформляются в PR со ссылкой для ревью.
* Деплой на сервер запускается только после ревью и мерджа PR в `main`.

### 2. Чистый код и универсальность (Multi-tenancy)
* Никакого хардкода конкретной предметной области в кодовой базе (например, табачной продукции, электроники, одежды). Система обслуживает разных клиентов из разных доменов.
* Соблюдение SOLID, DRY, KISS. Отсутствие дублирования кода.
* 100% прохождение всех unit-тестов перед каждым коммитом.
