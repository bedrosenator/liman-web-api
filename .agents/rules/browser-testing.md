# 🚫 Ограничение на запуск браузерного тестирования (Browser Subagent & Automated Browser Testing)

Все AI-агенты обязаны строго соблюдать следующее правило:

## Главный запрет
**Категорически ЗАПРЕЩЕНО автоматически запускать инструмент `browser_subagent` и любое автоматизированное тестирование в браузере (клики, заполнение форм, навигация, снятие скриншотов браузерным агентом) без ПРЕДВАРИТЕЛЬНОГО ЯВНОГО подтверждения от пользователя.**

### Правила поведения:
1. **Никаких скрытых/автономных запусков браузера:**
   - Если задача касается исправления стилей, верстки, кнопок, форм или логики, агент НЕ ДОЛЖЕН самостоятельно запускать `browser_subagent` для "визуальной проверки", "прокликивания" или создания скриншотов.
   - Запуск `browser_subagent` разрешён **ТОЛЬКО** если пользователь в текущем запросе прямым текстом попросил:
     - *"Проверь в браузере"*
     - *"Запусти браузерный тест"*
     - *"Заполни форму и сделай скриншот"*
     - Либо явно ответил согласием на вопрос агента о запуске браузера.

2. **Как проверять изменения по умолчанию:**
   - Модульные и интеграционные тесты (`vitest run`, `npm test`, `jest`).
   - Проверка типов и сборки (`tsc -b`, `npm run build`).
   - Линтинг (`oxlint`, `eslint`).
   - Тщательный статический анализ CSS/DOM/TSX файлов.

3. **Если агент считает, что требуется браузерный тест:**
   - Агент обязан сначала спросить у пользователя:  
     *"Хотите, чтобы я запустил браузерного агента для автоматической проверки и снятия скриншота?"*  
   - И ждать явного подтверждения пользователя перед вызовом `browser_subagent`.
