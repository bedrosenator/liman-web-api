# TASK-27: Вебхуки Хорошоп: авто-списание остатков при покупке и вебхук создания товара с тумблерами управления

- **ID:** TASK-27
- **Эпик:** Horoshop Webhooks & Real-time Sync
- **Статус:** Planned
- **Приоритет:** High
- **Исполнитель:** Backend & Frontend Agent

---

## 🎯 Цели

1. **Тумблер включения/отключения вебхука списания остатков при заказе (покупке)**:
   - В Клиентском портале и Панели администратора добавить наглядный переключатель:
     `⚡ Списание остатков при заказе (Вебхук покупок)`.
   - Если выключен — вебхук игнорирует события покупок или логирует их без изменения БД Limansoft.
   - Если включен — при поступлении заказа в Хорошоп остатки мгновенно списываются в таблице `name2ost` базы Limansoft.
   - В UI отображать готовый Webhook URL для вставки в админку Хорошоп:
     `https://{domain}/api/v1/horoshop/{tenantId}/webhook/order`.

2. **Вебхук и тумблер автоматического создания/выгрузки товара**:
   - Добавить тумблер:
     `📦 Автоматический экспорт нового товара (при создании)`.
   - Поддержка двух сценариев:
     - **Сценарий А (Limansoft → Хорошоп):** При появлении нового товара в БД Limansoft (по триггеру или вебхуку локальной MariaDB) товар мгновенно отправляется и создается в каталоге Хорошоп.
     - **Сценарий Б (Хорошоп → Limansoft):** Входящий вебхук от Хорошоп при создании товара на сайте:
       `POST /api/v1/horoshop/{tenantId}/webhook/product-created`, который регистрирует карточку товара в Limansoft.
   - Тумблер в настройках портала позволяет гибко включать/выключать этот механизм.

---

## 🏗️ Архитектурные требования

### 1. Модель данных тенанта (`Tenant`)
Добавить поля конфигурации:
- `horoshopOrderWebhookEnabled: boolean` (по умолчанию `true`) — активность вебхука списания остатков при покупке.
- `horoshopProductCreationWebhookEnabled: boolean` (по умолчанию `false`) — активность вебхука/триггера создания товара.
- `horoshopWebhookSecret?: string` — секретный токен для верификации подписи вебхуков.

### 2. Логика вебхуков на бэкенде
- **`POST /api/v1/horoshop/:tenantId/webhook/order`**:
  - Проверяет флаг `tenant.horoshopOrderWebhookEnabled`.
  - Если флаг выключен: возвращает `{ success: false, message: 'Вебхук заказов отключен в настройках тенанта' }` и делает запись в Activity Feed.
  - Если включен: производит списание и фиксирует событие в аудите.
- **`POST /api/v1/horoshop/:tenantId/webhook/product`**:
  - Принимает события создания или обновления товара (`product.create`).
  - Проверяет `tenant.horoshopProductCreationWebhookEnabled`.
  - При активности создает товар в каталоге Limansoft либо инициирует быструю синхронизацию карточки.

### 3. Пользовательский интерфейс (Frontend)
- В блоке **«Настройки Хорошоп API»** добавить секцию **«Вебхуки реального времени» (Real-time Webhooks)**:
  - **Тумблер 1**: `Списание остатков при покупке (Вебхук заказов)` + кнопка скопировать Webhook URL.
  - **Тумблер 2**: `Создание товара по вебхуку` + кнопка скопировать Webhook URL.
  - Бейджи статуса (Активен / Неактивен).
- В форме редактирования тенанта в SuperAdmin (`TenantModal.tsx`) продублировать эти переключатели на вкладке «Хорошоп».
