# TASK-21: Модули интеграций для маркетплейсов Prom.ua, Rozetka и WooCommerce в Личном Кабинете

- **ID:** TASK-21
- **Эпик:** Web Admin & Client Portal
- **Статус:** Backlog
- **Приоритет:** Medium
- **Исполнитель:** Frontend & Integration Agent

---

## 🎯 Цель
Разработать клиентские разделы для платформ **Prom.ua**, **Rozetka** и **WooCommerce** в личном кабинете магазина, выдержанные в едином стиле с модулем Хорошопа: диагностический индикатор подключения, формы доступов, генерация фидов, кнопки запуска синхронизации и **полная поддержка двух языков (RU / UK)**.

---

## 🏗️ Архитектура и функциональные требования

### 1. Модуль интеграции: Prom.ua
- **Статус и реквизиты**:
  - Индикатор связи по результату `GET /api/v1/prom/:tenantId/ping`;
  - Форма: `Prom API Key` (с кнопкой проверки ключа);
  - Тумблер автоматической выгрузки каталога и остатков.
- **Действия и фиды**:
  - Персональный URL YML/XML фида: `https://.../api/v1/prom/{tenantId}/feed.xml` с кнопкой «Скопировать / Скопіювати»;
  - Кнопка **«⚡ Синхронизировать остатки и цены / Синхронізувати залишки та ціни зараз»** (`POST /api/v1/sync/:tenantId/stock`);
  - Карточка с адресом вебхука заказов: `https://.../api/v1/prom/{tenantId}/webhook/order` с инструкцией по вставке в кабинет Prom.

### 2. Модуль интеграции: Rozetka Marketplace
- **Статус и реквизиты**:
  - Индикатор связи по результату `GET /api/v1/rozetka/:tenantId/ping`;
  - Форма: `Username / Client ID` и `Password / Client Secret` (с кнопкой проверки Seller API авторизации);
  - Тумблер автоэкспорта.
- **Действия и фиды**:
  - Персональный URL XML-фида Rozetka: `https://.../api/v1/rozetka/{tenantId}/feed.xml`;
  - Кнопка **«⚡ Обновить остатки и цены / Оновити залишки та ціни в Rozetka»** (`POST /api/v1/rozetka/:tenantId/sync`);
  - Карточка вебхука заказов Rozetka.

### 3. Модуль интеграции: WooCommerce
- **Статус и реквизиты**:
  - Индикатор связи `GET /api/v1/woocommerce/:tenantId/ping`;
  - Форма: `URL магазина / URL магазину`, `Consumer Key` (`ck_...`), `Consumer Secret` (`cs_...`);
  - Тумблер: `Two-Way Sync (двусторонний обмен новинками / двосторонній обмін новинками)`;
  - Кнопка **«📥 Скачать WordPress-плагин (.zip) / Завантажити WordPress-плагін (.zip)»** — отдает скомпилированный плагин `limansoft-sync-woocommerce.zip` в 1 клик.
- **Действия**:
  - Кнопка **«⚡ Пакетный Push каталога / Пакетний Push каталогу в WooCommerce»**;
  - Кнопка **«📦 Обновить остатки и цены / Оновити залишки та ціни»**;
  - Кнопка **«📤 Импортировать товары с сайта / Імпортувати товари з сайту в Limansoft»**.

### 4. Динамическое скрытие неактивных интеграций и мультиязычность (RU / UK)
- Если клиент подключил только «Хорошоп», разделы Prom и Rozetka помечаются бейджем *«Доступно для подключения / Доступно для підключення»*.
- Все интерфейсы, инструкции, плейсхолдеры и нотификации полностью переведены на Русский и Украинский языки через `LanguageContext`.

### 5. Тестирование модулей (Frontend Vitest)
- **Компонентные тесты (Vitest + React Testing Library)**:
  - Тестирование переключения вкладок интеграций (Prom, Rozetka, WooCommerce);
  - Тестирование кнопки скачивания плагина WooCommerce (`/api/v1/woocommerce/plugin/download`);
  - Проверка сохранения реквизитов и отображения бейджей статусов;
  - Проверка перевода всех вкладок при смене языка.
