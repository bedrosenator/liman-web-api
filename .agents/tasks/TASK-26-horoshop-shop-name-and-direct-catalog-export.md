# TASK-26: Динамическое название магазина Хорошоп и прямой экспорт каталога в 1 клик (без ручного фида)

- **ID:** TASK-26
- **Эпик:** Horoshop Integration & Client Portal
- **Статус:** Planned
- **Приоритет:** High
- **Исполнитель:** Backend & Frontend Agent

---

## 🎯 Цели

1. **Динамическое название магазина в шапке Клиентского портала**:
   - Избавиться от хардкода названия тенанта `Columb Shop (Локальная MariaDB)` в заголовке личного кабинета.
   - Автоматически подтягивать реальное название магазина из Хорошоп (через API Хорошоп или поле `horoshopShopTitle` / `horoshopDomain`) с возможностью ручного редактирования.
2. **Прямой экспорт каталога из Limansoft в Хорошоп по одной кнопке**:
   - Добавить в Action Hub кнопку **«🚀 Экспортировать каталог в Хорошоп»** (в 1 клик).
   - Клиенту больше не нужно вручную копировать ссылку на XML-фид и настраивать импорт в админке Хорошоп: система сама считывает каталог из базы Limansoft (товары, цены, остатки, фото, категории) и отправляет пакетно в API Хорошоп (`/api/catalog/import/`).

---

## 🏗️ Архитектурные предложения и решения

### 1. Подтягивание названия магазина Хорошоп
* **Проблема:** Сейчас в шапке отображается `tenant.name` (`Columb Shop (Локальная MariaDB)`), которое задается при сидировании в `tenant.service.ts`.
* **Решение:**
  - В сущность `Tenant` добавляем опциональное поле `horoshopShopTitle: string`.
  - При успешном подключении к API Хорошоп (`ping` или первый запрос) запрашиваем метаданные магазина / страницы через API Хорошоп или парсим заголовок главной страницы домена магазина, сохраняя официальное имя магазина в `horoshopShopTitle`.
  - В заголовке `ClientPortalPage.tsx` приоритет отображения:
    `tenant.horoshopShopTitle || tenant.horoshopDomain || tenant.name`.

### 2. Прямой экспорт каталога без возни со ссылками на фид
* **Вариант А (Прямой Push через API — Рекомендуемый):**
  - Кнопка в UI: **«Экспорт товаров в Хорошоп»**.
  - Модальное окно с выбором параметров:
    - Режим: Только новые товары / Обновить существующие / Полная перезапись.
    - Что выгружать: Цены, Остатки, Описания, Фотографии, Категории.
  - По нажатию запускается BullMQ-задача `export-liman-to-horoshop`.
  - Воркер порциями по 50-100 товаров отправляет структурированный JSON в эндпоинт Хорошоп `/api/catalog/import/`.
  - В UI отображается прогресс-бар в реальном времени (0-100%) и детальная статистика (создано, обновлено, пропущено, ошибок).
* **Вариант Б (Сохранение фида как альтернативы):**
  - Ссылку на фид оставляем в скрываемом блоке «Для опытных / Дополнительно» на случай, если клиент настроил автоматический парсинг по расписанию внутри самого Хорошопа.

## 📋 План реализации

1. **Backend**:
   - Расширить `HoroshopApiClient` методами получения информации о магазине и пакетного создания/обновления каталога через `/api/catalog/import/`.
   - Создать очередь и процессор BullMQ `ExportCatalogToHoroshopProcessor`.
   - Добавить эндпоинт `POST /api/v1/horoshop/:tenantId/export/catalog` со статусом выполнения.
2. **Frontend**:
   - Создать компонент `HoroshopExportModal.tsx` с прогрессом и статистикой.
   - Добавить кнопку вызова экспорта в Action Hub `ClientPortalPage.tsx`.
   - Отображать реальное название магазина в заголовке `ClientPortalPage.tsx`.
