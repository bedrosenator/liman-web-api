# TASK-25: Автономный Веб-Паук для поиска фото и обогащения описаний товаров в WooCommerce

## Статус: В бэклоге (Отложено / Запланировано на будущее) ⏳

## Описание задачи
Реализация надежного и производительного фонового сервиса («Веб-Паук» / Web Spider) для автоматического поиска и обогащения медиа-контентом каталога товаров WooCommerce, импортированных из учетной системы Limansoft / MariaDB (`columbDB`):

1. **Фоновый сборщик и очередь задач**:
   - Перенос тяжелых сетевых HTTP-запросов и загрузки картинок в фоновую очередь (BullMQ в `liman-web-api` либо WP Background Processing / Action Scheduler).
   - Защита от таймаутов PHP и блокировок веб-сервера.
   - Пакетная обработка позиций с индикацией прогресса (процент выполнения, текущий обрабатываемый SKU).

2. **Поиск и фильтрация изображений**:
   - Интеграция с поисковыми API изображений (Bing Images API, Google Custom Search, DuckDuckGo).
   - Автоматическая фильтрация по разрешению (минимум 800x800 px), соотношению сторон и цензурным фильтрам (SafeSearch).
   - Проверка релевантности по названию бренда и вкуса/модели.

3. **Генерация структурированных описаний**:
   - Формирование аккуратных HTML-шаблонов характеристик (бренд, объем, тип никотина, крепость, количество тяг/затяжек).
   - Поддержка двуязычности Polylang (генерация синхронных украинских и русских версий описаний).

4. **Медиа-библиотека WordPress**:
   - Загрузка изображений на сервер WooCommerce через `media_sideload_image`.
   - Назначение главного изображения (`_thumbnail_id`) и формирование галереи (`_product_image_gallery`).
   - Автоматическая генерация WebP миниатюр.

5. **Режим модерации**:
   - Опция предварительного предпросмотра найденных фото перед заменой в карточке товара.
