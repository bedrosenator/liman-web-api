## 🎯 Цель
Развернуть клиентское SPA-приложение на **React + Vite + TypeScript** внутри репозитория (`client/`) с изолированной архитектурой двух пространств:
1. **Панель Супер-Админа (`/superadmin`)** — управление всеми клиентами в SQLite, единая матрица настроек всех магазинов, глобальные очереди BullMQ;
2. **Личный Кабинет Клиента (`/portal/:tenantId`)** — изолированное брендированное пространство конкретного магазина с виджетами интеграций.

Внедрить полноценную **мультиязычность (i18n)** с поддержкой Русского и Украинского языков, а также настроить **высокопроизводительную раздачу статических файлов через Nginx Reverse Proxy для нулевой нагрузки на Event Loop Node.js**.

## 🏗️ Архитектура и функциональные требования

### 1. Мультиязычность (i18n: Русский + Украинский)
- **Контекст локализации (`client/src/context/LanguageContext.tsx`)**:
  - Словарь переводов на двух языках: `ru` (русский) и `uk` (украинский);
  - **Логика определения языка по умолчанию**:
    1. Проверка `localStorage.getItem('liman_lang')`;
    2. Если в хранилище пусто — проверка языка браузера (`navigator.language`): если начинается с `uk`, автоматически выставляется `uk`;
    3. Во всех остальных случаях — язык по умолчанию `ru` (русский);
  - Сохранение выбранного пользователем языка в `localStorage` (`liman_lang`).
- **Компонент переключателя языка (`LanguageSwitcher`)**:
  - Компактный переключатель в шапке (Header) с флагами/лейблами: `RU` / `UK`;
  - Мгновенная реактивная смена текстов без перезагрузки страницы.

### 2. Структура проекта `client/` и сборка
- Проект на Vite + React 19 + TypeScript.
- Сборка: `vite build` компилирует статику в директорию `public/app` бэкенда.
- NestJS контроллер `AdminController` настраивается на отдачу SPA с поддержкой HTML5 History API как дефолтный dev-fallback.

### 3. Разгрузка Node.js Event Loop: Раздача статики через Nginx
- **Проблема**: При одновременной работе десятков пользователей скачивание JS-бандлов (по 1-2 МБ), CSS и шрифтов через процесс Node.js блокирует Event Loop, увеличивая задержки API и генерации XML-фидов.
- **Решение (Nginx Reverse Proxy & Static Cache)**:
  - Создание конфигурации `docker/nginx.conf`:
    - **Статика SPA (`/app/assets/*`, `.js`, `.css`, `.png`, `.svg`)**: отдается напрямую Nginx с диска на уровне ядра ОС (`sendfile on`), минуя Node.js;
    - **Агрессивное кэширование**: `Cache-Control: public, max-age=31536000, immutable`, сжатие `gzip on` / `brotli`;
    - **SPA Routing**: `try_files $uri $uri/ /app/index.html`;
    - **API Проксирование**: запросы `/api/*` прозрачно проксируются в NestJS (`proxy_pass http://api:3000`);
  - Обновление `docker-compose.yml`: добавление легковесного сервиса `nginx:alpine` перед контейнером `liman-web-api`.

### 4. Дизайн-система «Limansoft Enterprise Dark»
- **Палитра**:
  - Фоновые слои: Slate Black (`#0B0F19`), Card Surface (`#111827`), Border Glow (`#1F2937` / `#374151`);
  - Акценты: Indigo/Electric Blue (`#6366F1`, `#3B82F6`), Кибер-циан (`#06B6D4`);
  - Статусы: Emerald Green (`#10B981` — активен/успех), Amber (`#F59E0B` — предупреждение/очередь), Rose (`#EF4444` — сбой/ошибка).
- **Типографика**: Inter + JetBrains Mono (для API-ключей, логов и SKU).
- **Компоненты**:
  - Иконки: `lucide-react` (интеграции, статус-индикаторы, кнопки копирования);
  - Toast-система уведомлений (всплывающие сообщения о статусе операций);
  - Skeleton-заглушки во время загрузки данных из API;
  - Glassmorphism карточки (`backdrop-blur-md`).

### 5. Авторизация и маршрутизация
- **Изолированные роуты**:
  - `/login` — экран входа (ввод Master Key для админа или вход по ключу тенанта);
  - `/superadmin/*` — защищенный раздел супер-админа (только при наличии валидного Master API Key);
  - `/portal/:tenantId` — клиентский портал. Защищен проверкой ключа тенанта или Master Key.
- **Безопасность сессии**:
  - `sessionStorage` / `localStorage` хранение токена сессии;
  - Поддержка входа по ссылке-токену: `https://.../portal/columb?token=...` с автоматическим сохранением и очисткой чувствительного параметра из адресной строки браузера;
  - При попытке доступа к чужому тенанту — автоматический редирект на экран авторизации с уведомлением о нарушении прав доступа.

### 6. Тестирование фронтенда (Vitest + React Testing Library)
- Настройка тестового окружения: `vitest`, `@testing-library/react`, `@testing-library/jest-dom`, `jsdom`;
- Скрипт `npm run test` в директории `client/`;
- Обязательное покрытие тестами:
  - `LanguageContext`: проверка RU по умолчанию, автоопределения языка браузера (UK), переключения и сохранения в `localStorage`;
  - `AuthGuard / ProtectedRoute`: проверка редиректов на `/login` при отсутствии ключа, проверка доступа к `/superadmin` и `/portal/:tenantId`;
  - `ApiInterceptor`: проверка автоматического добавления заголовка `x-api-key` и обработки 401/403.
