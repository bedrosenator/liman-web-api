# TASK-20: Личный кабинет клиента и модуль интеграции с Хорошоп (Horoshop Portal)

- **ID:** TASK-20
- **Эпик:** Web Admin & Client Portal
- **Статус:** Backlog
- **Приоритет:** High
- **Исполнитель:** Frontend & Integration Agent

---

## 🎯 Цель
Создать в личном кабинете клиента (`/portal/:tenantId`) интуитивно понятный, визуально привлекательный раздел управления интеграцией с платформой **Хорошоп (Horoshop)** с полной поддержкой **мультиязычности (RU / UK)**. Концепция: интерфейс «в 1 экран» без лишних технических сложностей для владельца магазина.

---

## 🏗️ Архитектура и функциональные требования

### 1. Визуальный диагностический блок «Светофор» (3-Point Health Bar)
В шапке кабинета отображается 3 ключевых индикатора здоровья интеграции:
1. **База Limansoft**:
   - `🟢 На связи / На зв'язку` (отображает количество доступных товаров в каталоге, например: *5 768 SKU*) / `🔴 Недоступна`;
2. **Магазин Хорошоп**:
   - `🟢 Авторизован / Авторизовано` (вызов `GET /api/v1/horoshop/:tenantId/ping`, отображает домен магазина и валидный токен) / `🔴 Ошибка авторизации / Помилка авторизації` (с понятным описанием причины);
3. **Автоматическая синхронизация**:
   - `🟢 Включена / Увімкнено` (интервал каждые 15 / 30 / 60 мин, время до следующего запуска) / `⚪ Выключена / Вимкнено`.

### 2. Главные действия клиента (Action Hub)
- **Большая кнопка действия**:
  - **«⚡ Обновить остатки и цены сейчас / Оновити залишки та ціни зараз»**:
    - Вызов `POST /api/v1/horoshop/:tenantId/sync/prices-stocks`;
    - Анимация прогресса и моментальное уведомление с отчетом: *«Успешно обновлено 5 768 товаров / Успішно оновлено 5 768 товарів у Хорошоп»*.
- **Блок ссылки на XML-каталог**:
  - Карточка с готовой ссылкой: `https://.../api/v1/horoshop/{tenantId}/feed.xml`;
  - Кнопка **«📋 Скопировать ссылку / Скопіювати посилання для Хорошоп»**;
  - Кнопка **«↗ Открыть фид / Відкрити фід»** (просмотр XML в новой вкладке).

### 3. Форма настройки API-доступа
- Лаконичная форма настройки магазина:
  - `Домен сайта / Домен сайту` (например: `shop724088.horoshop.ua`);
  - `API Логин / API Логін` (системный логин администратора, например: `liman_api`);
  - `API Пароль` (с кнопкой показать/скрыть 👁);
  - Тумблер: `Включить автоматическое обновление / Увімкнути автоматичне оновлення цін та залишків`;
  - Выбор частоты запуска: `15 мин / 15 хв`, `30 мин / 30 хв`, `60 мин / 60 хв`.
- Кнопка **«💾 Сохранить настройки / Зберегти налаштування»**.

### 4. Журнал активности (Activity Feed / Audit Stream)
- Хронологическая лента последних событий синхронизации:
  - *«14:15 — Автосинхронизация: обновлены остатки по 12 товарам в Хорошоп / Автосинхронізація: оновлено залишки по 12 товарах у Хорошоп»*;
  - *«13:42 — Заказ #10421 из Хорошоп: списано 2 шт (tcod 7711) в Limansoft / Замовлення #10421 з Хорошоп: успішно списано залишок у Limansoft»*;
  - *«12:00 — XML-фид сгенерирован (5 768 товаров) / XML-фід сформовано для Хорошоп (5 768 товарів)»*.
- Предотвращает вопросы в техподдержку («работает ли сейчас обмен?»).

### 5. Пошаговый мастер подключения (3-Step Wizard)
- Сворачиваемая карточка подсказок для нового клиента на выбранном языке (RU/UK):
  1. *Шаг 1 / Крок 1:* Создать пользователя в админке Хорошоп (**Настройки → Пользователи** / **Налаштування → Користувачі**) с ролью `owner`.
  2. *Шаг 2 / Крок 2:* Указать логин и пароль в форме и нажать «Сохранить» / «Зберегти».
  3. *Шаг 3 / Крок 3:* Скопировать ссылку на фид и добавить её в Хорошоп (**Экспорт/Импорт → Импорт товаров** / **Експорт/Імпорт → Імпорт товарів**).

### 6. Мультиязычность интерфейса (i18n: RU / UK)
- Все надписи, бейджи, подсказки, подсказки шагов онбординга, ошибки API и toast-уведомления полностью локализованы на Русский и Украинский языки и управляются через глобальный переключатель языка.

### 7. Тестирование модуля (Frontend Vitest + E2E Mock)
- **Компонентные тесты (Vitest + React Testing Library)**:
  - Тестирование виджета диагностики «Светофор» (проверка рендеринга состояний: зеленый, желтый, красный);
  - Тестирование кнопки ручной синхронизации (дизейбл кнопки во время запроса, показ лоадера, обработка ошибок);
  - Тестирование копирования ссылки на фид в буфер обмена (`navigator.clipboard.writeText`);
  - Валидация формы настроек Хорошоп API и маскирования пароля.
