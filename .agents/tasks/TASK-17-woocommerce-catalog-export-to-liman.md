# TASK-17: Выгрузка товаров из магазина WooCommerce обратно в учетную БД Limansoft (MariaDB)

- **ID:** TASK-17
- **Эпик:** WooCommerce Интеграция & Двусторонняя синхронизация
- **Статус:** Backlog (Очередь #2, частично реализовано в TASK-14 и TASK-24)
- **Приоритет:** Medium
- **Исполнитель:** Full-Stack & Integration Agent

> **Примечание о готовности:** Ядро двухстороннего импорта каталога из WooCommerce в `name2`, `name2ost`, `namedesc` (включая скачивание фото в BLOB) и эндпоинты `POST /woocommerce/:tenantId/import/products` уже реализованы в **TASK-14**. В плагине WordPress в **TASK-24** также созданы классы `class-migrator.php` и `class-direct-db.php`. В рамках TASK-17 основной фокус — разработка пользовательского интерфейса (кнопка, модальное окно выбора режима, AJAX progress-bar) в панели WordPress.

---

## 🎯 Цель
Предоставить администраторам магазина и товароведам удобный и безопасный механизм выгрузки товаров из WooCommerce обратно в учетную базу данных **Limansoft** (MariaDB: `name2`, `name2ost`, `namedesc`, `strihcod`) с возможностью ручного или фонового запуска прямо из панели управления WordPress или через REST API.

---

## 🏗️ Функциональные требования и сценарии

### 1. Пользовательский интерфейс в WordPress плагине (`limansoft-sync-woocommerce`)
- Добавить в сайдбар страницы **WooCommerce → Limansoft Sync** карточку выгрузки в Limansoft:
  - Кнопка **«📤 Вивантажити каталог до Limansoft»**.
  - Опции выгрузки (модальное окно или переключатели):
    - `Тільки нові товари` (у которых нет SKU или SKU не является числовым `tcod` Limansoft);
    - `Повний каталог` (обновление всех товаров, включая существующие).
  - Индикатор прогресса в реальном времени (AJAX progress-bar с процентом и счётчиком обработанных товаров).
  - Итоговый отчет: сколько товаров создано, обновлено, пропущено и возникшие ошибки.

### 2. Серверная обработка в `liman-web-api`
- Расширение существующего механизма BullMQ / REST API для поддержки выборочной выгрузки:
  - Фильтрация по статусам (только `publish` или включая `draft`/`pending`);
  - Поддержка постраничной выборки товаров из WooCommerce API пачками (batching);
  - Атомарное создание товаров через `insertProductMaster` с выделением `MAX(tcod) + 1`;
  - Скачивание до 5 медиа-файлов и запись в BLOB-поля `namedesc` (`photo`, `photo2`...);
  - Запись остатка в целевую колонку склада тенанта (`name2ost.skl_k`);
  - Обратная синхронизация: запись присвоенного `tcod` в метаполе `_sku` товара WooCommerce.

### 3. Обработка вариативных товаров и категорий
- Корректная обработка WooCommerce Variable Products: создание отдельной записи в `name2` для каждой активной вариации с уникальным SKU/tcod.
- Сопоставление категорий WooCommerce с таблицей `groups` в MariaDB с сохранением иерархии.

### 4. Безопасность и защита данных
- Защита от зацикливания синхронизации (loop prevention) через WP transients и маркеры источника.
- Настройка прав доступа (опция защиты от непреднамеренной перезаписи цен и складских остатков в Limansoft).
