## 🎯 Цель
Разработать и внедрить серверную систему лицензирования и защиты для коммерческого WordPress-плагина `limansoft-sync-woocommerce` на базе SaaS-архитектуры `liman-web-api`. Обеспечить контроль подписки, привязку к разрешенным доменам, тарифные ограничения и приватный сервер автоматических обновлений плагина.

---

## 🏗️ Архитектура и уровни защиты

### 1. Серверная модель лицензирования в `liman-web-api`
- **Расширение сущности Tenant (`tenant.entity.ts`)**:
  - `licenseKey: string` — уникальный лицензионный ключ формата `LSW-XXXX-XXXX-XXXX-XXXX`.
  - `licenseStatus: 'active' | 'expired' | 'suspended' | 'trial'` — статус лицензии.
  - `expiresAt: Date` — дата и время окончания действия подписки/триала.
  - `allowedDomains: string[]` — список доменов магазинов, которым разрешено использовать лицензию.
  - `plan: 'starter' | 'business' | 'enterprise'` — тарифный план клиента.
  - `maxProducts: number` — ограничение на максимальное количество синхронизируемых товаров по тарифу.
- **Middleware / Guard проверки лицензии (`LicenseGuard`)**:
  - Перехват всех запросов к маршрутам `/api/v1/woocommerce/:tenantId/*`.
  - Валидация:
    1. Проверка активности тенанта (`tenant.isActive === true`).
    2. Проверка статуса лицензии и срока (`now <= tenant.expiresAt`).
    3. Проверка домена клиента (`Origin` / `Referer` / параметр `domain` входит в `allowedDomains`).
  - При непрохождении проверок: возврат статус-кодов `403 Forbidden` или `402 Payment Required` с понятным описанием причины (`LICENSE_EXPIRED`, `DOMAIN_MISMATCH`, `MAX_PRODUCTS_EXCEEDED`).
- **Лицензионный API-эндпоинт**:
  - `POST /api/v1/license/verify` — публичный эндпоинт верификации лицензии для плагина:
    - Входные параметры: `{ licenseKey, domain, pluginVersion }`.
    - Ответ: `{ valid: boolean, status: string, plan: string, expiresAt: string, daysRemaining: number, maxProducts: number, features: string[] }`.

### 2. Лицензирование и валидация в плагине WordPress (`limansoft-sync-woocommerce`)
- **Поле ввода License Key в админ-панели**:
  - Добавить блок лицензирования в `settings-page.php`.
  - Статус подписки: зеленый/желтый/красный бейдж («Активна до 13.09.2027», «Осталось 5 дней», «Истекла»).
  - Кнопка «Активировать / Проверить лицензию».
- **Кеширование и фоновая проверка**:
  - Результат валидации кешируется в `transient` WordPress (`lsw_license_info`) на 12–24 часа.
  - Крон-задача раз в сутки обновляет статус лицензии.
- **Ограничения интерфейса при недействительной лицензии**:
  - Блокировка кнопки «Синхронізувати зараз».
  - Остановка фонового WP-Cron расписания синхронизации.
  - Баннер в шапке панели плагина с предупреждением и прямой ссылкой на продление подписки.

### 3. Приватный сервер автоматических обновлений (Auto-Updater Engine)
- **API сервер обновлений (`liman-web-api`)**:
  - `GET /api/v1/plugin/woocommerce/update-check`:
    - Проверяет `licenseKey` и `version`.
    - Возвращает манифест обновления: `{ version: '1.3.0', packageUrl: '...', changelog: '...', requiresWc: '7.0', testedUpTo: '9.0' }`.
  - `GET /api/v1/plugin/woocommerce/download`:
    - Выдача ZIP-архива обновления по одноразовому временному подписанному URL (Signed URL / JWT token) только для активных лицензий.
- **Клиент обновлений в плагине (`class-updater.php`)**:
  - Интеграция с нативными фильтрами WordPress:
    - `pre_set_site_transient_update_plugins` — проверка доступности новой версии.
    - `plugins_api` — отображение модального окна с описанием релиза и чейнджлогом.
    - `upgrader_package_options` — передача лицензионных заголовков при скачивании архива.
  - Возможность обновления плагина в 1 клик прямо из раздела «Плагины» в админке WordPress.
