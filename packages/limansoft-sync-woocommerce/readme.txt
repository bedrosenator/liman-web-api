Синхронізація каталогу, цін та залишків між Limansoft (liman-web-api) і WooCommerce.

== Description ==

**Limansoft Sync for WooCommerce** — це офіційний плагін для з'єднання вашого WooCommerce-магазину з товарно-обліковою системою **Limansoft** через `liman-web-api`.

= Основні можливості =

* **Повна синхронізація каталогу** — Завантаження всіх активних товарів з Limansoft до WooCommerce (назва, ціна, залишок, фото, категорія).
* **SKU-маппінг** — Код товару (tcod) з Limansoft автоматично стає SKU у WooCommerce.
* **Фото товарів** — Зображення завантажуються через Media API з BLOB-сховища Limansoft.
* **Автоматична синхронізація** — WP-Cron задача з інтервалами 15, 30 або 60 хвилин.
* **Увімкнення/вимкнення розкладу** — Один перемикач — і WP-Cron задача миттєво скасовується (без перезавантаження). Ручна синхронізація продовжує працювати.
* **Вебхук замовлень** — При оформленні замовлення в WooCommerce, залишки автоматично списуються в Limansoft через API.
* **Мультиклієнтність** — Один сервер `liman-web-api` може обслуговувати декілька магазинів (Tenant ID).

= Як це працює =

1. Встановіть плагін у ваш WooCommerce.
2. Перейдіть до WooCommerce → Limansoft Sync.
3. Введіть API URL, API Key і Tenant ID (отримайте в налаштуваннях liman-web-api).
4. Натисніть "Перевірити підключення" та "Синхронізувати зараз".
5. Увімкніть автосинхронізацію та виберіть інтервал.

== Installation ==

1. Завантажте `.zip` файл плагіну.
2. У WordPress Admin → Плагіни → Додати новий → Завантажити плагін.
3. Активуйте плагін.
4. Перейдіть WooCommerce → Limansoft Sync для налаштування.

== Frequently Asked Questions ==

= Де взяти API Key? =
API Key генерується автоматично при створенні клієнта (тенанта) в `liman-web-api`. Ключ можна переглянути через Swagger UI сервісу або отримати через `POST /api/v1/tenants/:id/rotate-key`.

= Чи безпечна передача даних? =
Так. Всі запити між плагіном і сервером захищені API ключем (заголовок `x-api-key`). Рекомендується використовувати HTTPS для вашого API сервера.

= Що таке Tenant ID? =
Це унікальний ідентифікатор вашого магазину в системі liman-web-api. Наприклад: `columb`, `shop1` тощо.

= Чи можна вимкнути автоматичне оновлення? =
Так. Зніміть галочку "Увімкнути автоматичну синхронізацію" — WP-Cron задача буде скасована миттєво. Ручна синхронізація та вебхуки продовжать працювати.

= Як часто можна оновлювати залишки? =
Рекомендовано 30-60 хвилин для великих каталогів (10 000+ товарів). Мінімум — 15 хвилин.
